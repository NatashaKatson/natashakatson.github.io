# Women’s rights country colors — removed

Removed on 29 October 2026 following concerns about accuracy. The country-score
view, map shading, legend, tooltip scores, supporting dataset and data builder
have been removed. Older shared views still open, with their obsolete color
setting ignored.

The 76 source-linked women’s-rights milestones remain available in Journeys,
search and the timeline. Their map markers remain off by default.
